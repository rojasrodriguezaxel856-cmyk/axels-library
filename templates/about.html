ℹ️ Acerca de mi_primera_web

📖 ¿Qué es esto?

Esta es mi primera aplicación web con Flask.

Es un gestor de biblioteca personal donde puedo:

  • ➕ Agregar libros con título y autor
  • ✏️ Editar la información de libros
  • 🗑️ Eliminar libros de mi biblioteca
  • 📚 Ver todos mis libros en una lista

🛠️ Tecnologías utilizadas:

  • Backend: Python + Flask
  • Base de datos: SQLite
  • Frontend: HTML + CSS + JavaScript
